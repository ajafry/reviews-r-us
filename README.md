# Reviews R Us

A simple Python project for demonstrating how GitHub Copilot Code Reviews work.

## Overview

This is a simple project that provides functionality for demonstrating how to perform code reviews using GitHub Copilot within
Visual Studio Code and GitHub.

## Getting Started

### Prerequisites

- Python 3.x

### Installation

1. Clone the repository
2. Navigate to the project directory

### Usage

Run the main application:
```bash
python main.py
```
